# 연구형 앱 · 3단계 「리서치」 (2026-11-13 · 문헌 조사 · 앱에 반영 안 됨)

대표님 결정(2026-11-13): 문헌 조사만, 참여자 데이터는 쓰지 않는다. **PubMed 검색 도구만** 썼고 API 크레딧·키는 쓰지 않았습니다.
아래는 PubMed 에서 가져온 **초록 수준**의 내용입니다 — 본문 전체를 읽지 않았고, 통계 수치는 초록에 적힌 것만 옮겼습니다. 논문 인구(연령·질환·모집 방식)가 우리 앱 사용자와 같다는 뜻이 아닙니다.

## A. 갈망 순간의 대처 · 상황 (연구 ① 금연 · ② 금주)

| 논문 (PubMed · DOI) | 초록이 말하는 것 | 우리 변수와의 관계 |
|---|---|---|
| Shiffman 외 2020, 비매일 흡연자 130명 EMA · [10.1007/s00213-020-05539-3](https://doi.org/10.1007/s00213-020-05539-3) | 유혹 976건 중 피운 147건. **피움과 넘김은 갈망 세기로는 갈리지 않았고**, 담배 단서(옆에서 피움 · 구하기 쉬움) · 술 · 나쁜 기분이 더 자주 따랐다. 행동 대처가 인지 대처보다 효과가 훨씬 컸다 | 우리 `others_smoking` · `cig_available` · `trig_coffee_alcohol` · `cope_*` 가 같은 종류의 칸. 「갈망 세기만으로는 결과를 못 가른다」는 점은 2단계 표의 `craving_level` 단독 분석을 조심해야 한다는 뜻 |
| Zhao 외 2023, 알코올 치료 참여자 181명 · 84일 EMA · [10.1037/adb0000931](https://doi.org/10.1037/adb0000931) | 그날 평균 갈망이 높을수록 금주 확률↓·과음 확률↑, 적응적 대처가 많을수록 금주 확률↑ | 금주 `daily` 의 `craving_mean_0_10` · `cope_*` 가 같은 구조 (치료 중인 임상 표본이라 우리 앱 사용자와 다름) |
| Waddell 외 2021, 빈번한 음주자 403명 · 21일 · [10.1037/adb0000696](https://doi.org/10.1037/adb0000696) | 나쁜 기분 → 갈망 ↑, 음주에는 갈망을 거쳐 영향 | 금주 `mood` → `craving_0_10` 관계를 먼저 보는 근거 |
| Pedersen 외 2021, 성인 음주자 229명 · 10일 · [10.1111/add.15740](https://doi.org/10.1111/add.15740) | 스트레스와 갈망의 순간 연관, 집단 간 차이 | `trig_stress` 가 두 앱의 **공통 상황 변수**인 이유(2단계) |
| Huang 외 2022, 하루 1~5개비 청년 41명 · [10.1016/j.drugalcdep.2022.109717](https://doi.org/10.1016/j.drugalcdep.2022.109717) | 흡연 기회가 높다고 느낄 때만 정서 각성과 갈망이 연결 | 금연의 `cig_available` 은 있고 **금주에는 「술을 바로 구할 수 있나」 칸이 없다** |

**읽고 남는 것**
1. 상황·대처·환경(구하기 쉬움 · 옆 사람)이 갈망 세기보다 결과를 더 잘 가른다는 보고가 있다 → 연구 ①②는 `craving_level` 하나로 끝내지 말고 **상황·대처·환경 칸을 중심**에 둔다.
2. 금주에 「술을 바로 구할 수 있었나」가 없다 — 화면 변경이므로 **질문으로만** 남긴다(아래 결정).
3. 이 논문들은 대부분 **알림이 울려 답하는 EMA**이거나 임상 표본이다. 우리 앱은 **본인이 눌러 적는 기록**이라 그대로 비교하지 않는다.

## B. 기록하지 않은 순간 (모든 연구 공통)

| 논문 (PubMed · DOI) | 초록이 말하는 것 | 우리에게 |
|---|---|---|
| Murray 외 2022, 청년 260명 · [10.1016/j.jad.2022.11.014](https://doi.org/10.1016/j.jad.2022.11.014) | 스트레스·부정 정서가 높을수록 **다음 알림을 놓칠 확률↑** — 결측이 무작위가 아닐 수 있다 | 우리 데이터는 힘든 순간일수록 **덜 적힐 가능성**을 분석에서 가정해야 한다 |
| Courvoisier 외 2012, 305명 · 7일 · [10.1037/a0026733](https://doi.org/10.1037/a0026733) | 평균 응답률 74.9%, 기간이 지나며 감소 | 응답률 하락은 흔한 현상 → 참여자별 기록 일수·간격을 결과와 함께 보고 |
| Martinez 외 2021, 직장인 757명 · [10.2196/22218](https://doi.org/10.2196/22218) | 초기 2주 순응이 이후 순응을 크게 설명(분산 62~66%) | 첫 2주 기록량을 「이탈 위험」 지표로 쓰되 **사람에게 불이익을 주는 데 쓰지 않는다** |
| Drexl 외 2025, 청소년 메타분석 · [10.2196/65710](https://doi.org/10.2196/65710) | 응답률 약 72%, 문항이 많을수록 수락률↓, 기간이 길수록 유지율↓ | 청소년 표본 — **성인 앱에는 방향만 참고**. 기록 항목 수가 이탈과 관련될 수 있음 |

**읽고 남는 것**: 모든 결과 문장에 「기록한 순간 안에서」를 붙이고, 참여자별 **기록 일수 · 첫 2주 기록 수 · 마지막 기록일**을 `participant` 요약에 낼 수 있는지 4단계에서 본다(새 변수는 앱 화면이 아니라 내보내기 쪽 계산).

## C. 앱 둘을 합쳐 분석할 때의 변수 맞춤

PubMed 에서 「두 자가 기록 앱의 변수를 맞춘 분석」을 직접 다룬 논문은 **찾지 못했습니다**(검색 2회). 관련은 둘뿐입니다.

| 논문 (PubMed · DOI) | 초록이 말하는 것 | 우리에게 |
|---|---|---|
| Adnan 외 2021, 생리 주기 앱 리뷰 · [10.1097/MED.0000000000000682](https://doi.org/10.1097/MED.0000000000000682) | 앱마다 증상 문구·구체성이 크게 다르고 대부분 있음/없음만 기록해 **합쳐 분석하기 어렵다** | 2단계의 「항목은 반쯤만 겹친다」와 같은 문제 — 겹치는 항목만 공통 이름으로 |
| Baumgartner 외 2024, 병원·원격 모니터링 자료 · [10.3389/fmed.2024.1301660](https://doi.org/10.3389/fmed.2024.1301660) | 자료를 가명화하고 공통 자료 모델(OMOP CDM)로 맞춰 쓰는 연합 구조 | 병원 자료용이라 우리에게는 과함. **「가명화 → 공통 모델로 변환」 순서**만 참고 |

PubMed 는 의생명 범위라 컴퓨터과학·심리학 데이터베이스는 보지 못했습니다 — 이 칸은 **「없다」가 아니라 「이 방법으로는 못 찾았다」**입니다.

## 결정 질문

1. 금주 기록에 「술을 바로 구할 수 있었나」(예/아니오) 한 칸을 더할까요? (금연 `cig_available` 과 짝 · 화면 변경이라 따로 묻습니다)
2. 4단계(센싱 하드웨어 선정)로 가도 될까요? — 두 앱의 수동 입력 외에 **어떤 기기 값을 연구에 더할지**(날숨 CO · 걸음 · 심박 등)가 그 단계의 질문입니다.
