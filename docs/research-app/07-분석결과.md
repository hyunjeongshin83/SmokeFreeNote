# 연구형 앱 · 7단계 「분석·결과」 (2026-11-13 · 제안 + 합성 데이터 시험 · 앱에 반영 안 됨)

데이터가 한 줄도 나가지 않아도 할 수 있는 단계입니다. **실제 참여자 데이터는 쓰지 않았고**, 시드가 고정된 **합성(가짜) 기록**으로 「분석 → 결과 한 장」의 모양과 분석이 맞는지를 시험했습니다.
새로 더한 것: `tools/research-synth.cjs`(합성 기록 + 분석) · `tests/research-synth.test.mjs`(시험). **2026-11-14 에 금주 분석(`--app alcohol`)과 보정 시험을 더했습니다**(아래 6절). 앱·내보내기 코드는 바꾸지 않았습니다. `node --test tests/*.test.mjs` 119건 통과(기준선 117 + 2).

## 1. 분석이 하는 일 (연구 ①)

- 입력: 앱의 내보내기 `records` 표 그대로 (`research.js` `buildRecords` 를 거친 열 — 새 열 없음)
- 결과 변수: `lapse` = `slip`==1 (2단계의 방향 맞춤 — 금연은 `slip` 이 이미 1=피움)
- 조건 변수: 대처(`cope_*`) 하나씩
- 값: **(대처 있음) 피움 비율 − (없음) 피움 비율**, 그리고 **참여자 단위 부트스트랩 95% 구간**
- 왜 참여자 단위인가: 한 사람의 기록은 서로 닮았다. 기록 한 건 한 건을 독립으로 보면 구간이 지나치게 좁아진다(3단계의 결측 문제와 같은 계열의 주의).

## 2. 분석이 맞는지의 시험 — 양성·음성 대조

| 대조 | 만든 방법 | 기대 | 결과 |
|---|---|---|---|
| 양성 | 합성 기록에서 「산책」이 있으면 피울 확률을 25%p 낮춤 | 산책의 구간이 0 아래 | 통과 |
| 음성 | 효과를 심지 않음 (`--effect 0`) | **산책** 구간이 0 을 포함 | 통과 (아래 주의) |

두 대조가 모두 통과해야 분석이 「없는 효과를 만들지도, 있는 효과를 놓치지도」 않는다고 말할 수 있습니다. **이 시험은 계산이 맞다는 것이지 실제 효과가 있다는 것이 아닙니다.**

**음성 대조의 범위 (Codex 지적 · PR #92 로 바로잡음)**: 판정은 미리 정한 한 가지 대비(산책)만 봅니다. 대처 일곱 개를 한꺼번에 보므로 효과를 안 심어도 **우연히 한두 구간이 0 을 벗어날 수 있고**(구간 하나당 약 5%, 일곱 개 중 하나라도일 확률 약 30%), 시험이 쓰는 시드(`--seed 3`)에서는 실제로 `cope_brush` 가 그렇습니다. 도구는 이를 「다중 비교」 줄로 숫자만 알리고 판정에는 넣지 않습니다. **실제 분석에서는 한꺼번에 본 여러 구간 중 하나가 0 을 벗어난 것을 발견으로 읽지 않습니다**(미리 정한 대비만 판정하고 나머지는 탐색으로 표시). 여러 시드에서 「0 을 벗어나는 비율이 약 5% 인지」를 보는 보정 시험은 6절에 있습니다(2026-11-14).

## 3. 「결과 한 장」 — 이 모양으로 낸다

```
※ 합성(가짜) 기록 — 시드 1 · 참여자 60명 · 기록 3102건 · 심은 효과: 산책 -25%p
대처 방법              있음     없음      차이   95% 구간 (참여자 단위 부트스트랩 400회)
cope_water      29.0%  29.0%    0.0%p   [-3.7, 3.8]
cope_breath     30.3%  28.5%    1.8%p   [-1.8, 5.5]
cope_walk       10.3%  35.2%  -24.9%p   [-28.5, -21.2]  ← 구간이 0 을 포함하지 않음
cope_brush      29.0%  29.0%   -0.0%p   [-2.9, 3.0]
cope_gum        29.7%  28.8%    0.9%p   [-2.9, 5.3]
cope_call       29.5%  28.8%    0.7%p   [-2.8, 4.8]
cope_hold5      28.8%  29.0%   -0.3%p   [-3.8, 2.9]

읽는 법: 「차이」는 피움 비율의 차(대처 있음 − 없음)이며 효과·인과가 아니다. 구간이 0 을 포함하면 이 표본으로는 방향을 말하지 않는다.
다중 비교: 7개 중 1개의 구간이 0 을 벗어남 (심은 효과 하나가 포함됨)
검증: 심은 효과(산책)를 되찾았다.
```

한 장에 반드시 들어가는 네 줄(제안):
1. **누구·얼마나**: 참여자 수 · 기록 건수 · 참여자별 기록 일수 중앙값 (3단계: 기록 안 한 순간 단서)
2. **표**: 위와 같은 대처별 비교 (있음 · 없음 · 차이 · 구간)
3. **읽는 법 한 줄**: 「차이는 피움 비율의 차이며 효과·인과가 아니다. 구간이 0 을 포함하면 방향을 말하지 않는다」
4. **한계 한 줄**: 「기록한 순간 안에서의 결과이며, 힘든 순간일수록 덜 적혔을 수 있다」

**쓰지 않는 말**: 「효과 있다」 · 「금연에 성공하게 해 준다」 · 「안전한 …」 · 판정·진단 표현. 표의 이름은 「관계」로 부릅니다.

## 4. 아직 안 한 것 · 알려진 한계

- **금주(연구 ②)** 는 2026-11-14 에 만들었습니다(6절). 금연과 **같은 비교를 그대로 쓸 수는 없었습니다**(대처가 넘김 기록에만 있음 · 자동 기록).
- 합성 기록은 **대처 칸이 서로 독립**이라 현실의 상관(스트레스+산책 등)을 모릅니다. 여러 대처를 한꺼번에 보는 모형은 만들지 않았습니다.
- 한 사람 안의 변화(같은 사람이 산책한 순간 vs 안 한 순간)를 보는 설계는 아직입니다 — 사람 간 차이와 섞이지 않게 하려면 필요한 다음 분석입니다(3단계 문헌의 방법).
- 실제 데이터에서는 기록 수가 적은 참여자가 많을 수 있어 구간이 넓어집니다. 합성 60명·3천 건은 **잘 모인 경우**입니다.

## 6. 금주 분석 (연구 ②) — 2026-11-14 · 금주를 먼저 하라는 대표님 말씀

`node tools/research-synth.cjs --app alcohol` (금주 `research.js` 는 `ALC_DIR` 또는 이 폴더 옆 `NonAlcoholNote`). 같은 합성 기록·같은 참여자 단위 부트스트랩이고, 달라진 것은 셋입니다.

| | 금연 | 금주 |
|---|---|---|
| 결과 변수 `lapse` | `slip`==1 (피움) | `kind`==2 (마심) — 시험이 앱 저장 모양에서 이 값이 나오는지 확인 |
| 비교 | 대처 일곱 개 | **상황 여덟 개 + 갈망 높음(≥7) + 기분 나쁨** (열 개) |
| 미리 정한 대비 | 산책 | 모임·회식 |

**발견 1 — 금주는 「대처별 마심 비율」을 낼 수 없습니다.** 금주 앱은 「마셨어요」를 고르면 대처 칸을 숨깁니다(`NonAlcohol_app.html` 의 `l_cope_box` · 저장 때 `cope: drank ? [] : …`). 그래서 대처는 「넘김」 기록에만 남고, 대처가 있으면 마심 비율은 구조상 늘 0% 입니다. 금연 앱은 대처 칸이 늘 보이고 「피웠어요」가 따로라 이 문제가 없습니다. 2단계 표의 「공통 대처 넷」은 **금연에서만 마심·피움과 비교할 수 있습니다.** (시험이 이 가정을 앱 소스에서 확인합니다 — 앱이 바뀌면 시험이 알립니다.)

**발견 2 — 「5분 버티기」 완료 자동 기록이 모든 비교를 부풀립니다.** 두 앱 모두 5분 버티기를 끝내면 갈망·기분·상황이 비어 있고 대처만 「5분 버티기」인 「넘김」 기록을 자동으로 남깁니다(금연은 갈망 단계를 「보통」으로 채우고 원래 당김을 가리키는 `from` 이 있음, 금주는 갈망 0~10 이 없음). 합성 기록에 이런 기록 10% 를 섞어 분석했더니 **심지 않은 상황 일곱 개 중 여섯에서 「있음」이 3.4~7.5%p 높게 나왔고 그중 다섯은 구간이 0 을 벗어났습니다**(시드 1 · 상황이 비어 있는 자동 기록이 모든 비교의 「없음」 쪽에 쌓이기 때문). 금주는 **갈망 0~10 칸이 없는 기록을 빼면** 심은 효과(모임·회식 +25%p)만 0 밖에 남고 나머지는 0 근처로 돌아옵니다. 제외를 끄면 금주 시험 4건이 실패합니다.
- **금연은 같은 방법으로 못 뺍니다** — 자동 기록이 갈망 「보통」으로 채워져 수동 기록과 구분되지 않고, 내보내기에 `from` 도 없습니다. 그래서 금연의 `cope_hold5` 비교는 해석하지 않습니다(도구가 주의 줄을 냅니다). 구분하려면 내보내기에 **자동 기록 표시 한 칸**이 필요합니다 — 코드북 버전이 바뀌는 일이라 아래 결정 질문 3 으로 남깁니다.

**보정 시험 (지난번에 「아직 안 했다」고 적은 것)**: 효과를 안 심은 30 시드에서 미리 정한 대비의 구간이 0 을 벗어난 비율은 금연 **0/30**, 금주 **2/30**(기대 약 1.5). 시험은 7/30 이하를 요구합니다. 한 시드만 보면 5% 가 우연히 어긋나는 것이 정상이고(예: 금주 시드 7), 그래서 음성 대조는 한 시드가 아니라 이 비율로 믿습니다.
