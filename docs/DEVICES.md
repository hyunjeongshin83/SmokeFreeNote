# 금연노트 — 기기로 흡연을 잴 수 있나 (2026-09-25 조사)

「전자담배가 사용량을 재 주는가」와 「내 흡연 기록을 자동으로 모아 줄 IT 기기가 있는가」를 조사한 사실과 출처입니다.
**결정은 `DESIGN.md` 6절**에 있습니다. 앱 본체·기기는 손에 넣어 확인하지 못했고, 제조사 안내·논문·스토어 설명으로 썼습니다.

## 1. 한 줄

전자담배 기기는 퍼프 수를 **세고 있지만 우리 앱에 내주지 않습니다.** 스마트워치 동작 감지는 연구 단계이고 시계 앱이 따로 필요합니다.
CO 측정기는 제조사 앱에서만 읽힙니다. 삼성 헬스·애플 건강에는 흡연 항목 자체가 없습니다.
그래서 지금 할 수 있는 것은 **옮겨 적기(CO · 주간 퍼프)** 와 **시각·상황 패턴 통계**, **홈 화면 바로가기로 기록을 빠르게** 하는 것입니다.

## 2. 전자담배 기기 — 센싱은 되지만 통로가 없음

| 기기 | 앱 | 재는 것 | 밖으로 내주나 |
|---|---|---|---|
| IQOS ILUMA i (PMI) | IQOS 앱 · 블루투스 | 주간 퍼프 수, 사용 통계, FlexPuff(흡입 패턴 감지) | 앱 화면뿐. 공개 API 없음 |
| 릴 에이블 프리미엄 · 에이블 2.0 (KT&G) | My lil 앱 · 블루투스 · 성인 인증 | 기기 설정·정보, 남은 퍼프 수(기기 화면), 최근 연결 위치(기기 안에서만) | 사용 통계 내보내기 확인 못 함. 공개 API 없음 |
| JUUL2 | JUUL 앱 · 블루투스 · 팟 칩 | 일·주·월 퍼프 수 | 퍼프 데이터는 기기 안에 둠(기본). 공개 API 없음 |
| PAX Era Pro | PAX 앱 | 세션별 퍼프 | 공개 API 없음 |

- 블루투스 GATT 프로토콜은 전부 비공개입니다. 특허에는 「퍼프 수·남은 퍼프를 GATT 로 주고받는」 구조가 적혀 있지만(USPTO 12256786 · 12075842) 공개된 명세나 오픈소스 구현은 찾지 못했습니다.
- 그래서 **Web Bluetooth 로 우리 앱이 직접 읽는 것은 안 됩니다.** 서비스 UUID 를 모르고, 제조사 앱의 성인 인증·페어링이 앞에 있습니다.
- 대안: 제조사 앱이 보여 주는 **주간 퍼프·스틱 수를 기록 탭에 옮겨 적기.** (앱 「측정값」칸)

## 3. 스마트워치 — 연구용은 되지만 시계 앱이 필요

| 연구 | 무엇 | 결과 | 출처 (PubMed) |
|---|---|---|---|
| StopWatch (브리스틀, 2024) | 시계 가속도로 흡연 손동작 감지 → 시계 화면에 메시지 | n=18 · 2주 · 12/18 수용. **배터리·크기·알림 방식**이 걸림 | JMIR Form Res 2024 · https://doi.org/10.2196/56999 |
| Sense2Quit (컬럼비아, 2025) | 시계 + 앱, 흡연 손동작 AI | n=60 무작위 타당성 · 이탈 1명 · 사용성 높음. 금연율은 별도 | AIDS Behav 2025 · https://doi.org/10.1007/s10461-025-04659-1 · 프로토콜 https://doi.org/10.2196/49558 |
| Lumme (HIV, 2022) | 시계 센싱 앱 + NRT | n=40 · 7일 금연율 **차이 없음** | JMIR Form Res 2022 · https://doi.org/10.2196/28626 |
| SmokeBeat (임신부, 2021) | 시계 감지 + 인센티브 | 세 파일럿 모두 **개선 없음**, 실행 가능성은 있음 | JMIR Form Res 2021 · https://doi.org/10.2196/27801 |
| 체계적 문헌고찰 (2019, 86편) | 손목 IMU · 호흡 · 심전도 등 | **100% 정확한 것은 없고 대부분 실험실 검증** | Sensors 2019 · https://doi.org/10.3390/s19214678 |

- 동작 감지는 **Wear OS · watchOS 앱**이 있어야 합니다. 웹앱(PWA)에서는 시계 센서에 닿지 못합니다.
- 금연율을 올렸다는 근거는 아직 없습니다(수용성·타당성까지). 배터리가 반복해서 문제로 나옵니다.

## 4. 날숨 일산화탄소(CO) 측정기

| 기기 | 값 | 연결 | 우리 앱에서 |
|---|---|---|---|
| Bedfont iCOquit Smokerlyzer | 개인용 · 약 65달러 · 블루투스 | iCOquit 앱만 | ✗ 직접 못 읽음 |
| Pivot Breath Sensor | 개인용 · 블루투스 | Pivot 앱만 | ✗ |
| 보건소 금연클리닉 Smokerlyzer | 방문 때 측정 | — | ○ 값을 옮겨 적음 |

- 기준: Smart-T 시험은 **CO 6 ppm 이하**를 비흡연으로 봤습니다 (JAMA Netw Open 2025 · https://doi.org/10.1001/jamanetworkopen.2025.26691). iCOquit 은 다른 측정기와 비교해 임상 적용 가능한 수준으로 평가됐습니다 (Drug Alcohol Depend 2023 · https://doi.org/10.1016/j.drugalcdep.2023.110956).
- GATT 비공개라 Web Bluetooth 로 못 읽습니다.

## 5. 건강 플랫폼

- **애플 건강(HealthKit)**: 흡연·니코틴 항목이 없습니다. https://developer.apple.com/documentation/healthkit/data-types
- **Health Connect(삼성 헬스 포함)**: 활동·신체·주기·영양·수면·활력징후 여섯 범주뿐, 흡연 없음.
- 간접 신호(심박·수면·걸음)는 있으나 안드로이드·iOS **네이티브 앱**이어야 읽습니다. MediNote 의 HealthConnectManager 도 같은 이유로 아직 어느 화면에서도 안 불립니다.

## 6. 그 밖

- 스마트 라이터(Quitbit 단종 · 연구용 계측 라이터 + 손목 IMU: https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6387353/) — 시판품 없음.
- 심박 패턴으로 흡연을 잡는 HeartIt (2025, 저전력) — 연구 단계.
- 수동 퍼프 카운터 앱(Puff Count 류) — 결국 손으로 누르는 것. 우리 기록 탭과 같음.

## 7. 그래서 지금 앱이 하는 것 (DESIGN.md 6절)

1. **측정값 옮겨 적기** — CO ppm · 이번 주 퍼프/스틱. 통계 탭에 최근값과 직전값.
2. **담배 종류** — 일반 · 궐련형(스틱) · 액상(퍼프) 을 설정에서 고르고 단위·비용 계산을 맞춤.
3. **시각·상황 패턴** — 센서 대신 기록의 시각으로 「언제 많이 당기나」, 상황·기분 순위.
4. **홈 화면 바로가기** — 「당겨요」·「기록」(manifest shortcuts). 기록이 빠를수록 잘 남습니다(갈망→재발 평균 11분).
5. **내보내기·가져오기** — 폰을 바꿔도 기록이 따라옵니다. 서버 없음.

시계 앱·CO 측정기 연동은 **네이티브 앱 결정**(DESIGN.md 5절)이 먼저입니다.
