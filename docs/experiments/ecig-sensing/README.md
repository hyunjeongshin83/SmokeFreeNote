# 센싱 가능 전자담배 자동 수집 — 시뮬레이션 실험 (제안 단계)

2026-10-21 작성. 읽는 순서: `report.md` → 필요하면 `sim.py` 의 `PARAMS`.

**상태**: 제안·시뮬레이션입니다. 이 앱(금연노트)에는 아직 반영된 것이 없고, 지금 앱의 원칙(모든 기록은 이 기기의 `localStorage` 에만 · `docs/DESIGN.md`)과도 다릅니다.
보고서가 가정하는 서버 저장(Supabase `puff_log`)·약사 공유는 **건강 데이터가 기기 밖으로 나가는 일**이라 CLAUDE.md §2 에 따라 대표님 결정 전에는 만들지 않습니다.

**수치의 성격**: 가정한 생성 모형 위의 시뮬레이션 출력이며 실기기 측정이 아닙니다. 가정은 모두 보정 전입니다. 절대값이 아니라 설계안끼리의 상대 비교로 읽으세요.

`docs/DEVICES.md`(사실·출처만)와 달리 이 폴더는 가정과 추론을 포함합니다.

```
python3 sim.py            # 약 1분, results.json (시드 고정, 표준 라이브러리만)
python3 sim.py --quick
python3 sensitivity.py    # 실험 1 민감도
```
