# 연구실 자료 수신 (labUrl)

대표님 결정 (2026-11-11 · 채팅): 연구 참여를 켜면 **연구실 DB 로 업로드**. 연구실 DB 는 **Google 시트**(연구실 Drive 엑셀 틀 「연구실_…_DB틀.xlsx」과 같은 열).
기존 참여자 Drive 저장(`RESEARCH-EXPORT.md`)은 그대로 두고, `research-config.js` 의 **`labUrl` 이 있을 때만** 이 길로 갑니다.

## 지금 상태

**꺼져 있습니다.** `enabled:false` 가 기본값이고, `labUrl` · `consentText` · `consentVersion`(+ `irb`)이 채워지기 전에는 화면에 「연구 참여」 칸이 보이지 않으며 아무 데도 접속하지 않습니다.
동의 문구·IRB 번호는 아직 저장소에 없습니다 — 지어내지 않았습니다. **동의 문구에 「연구실로 보낸다」가 들어가야 합니다.**

## 길

```
참여자 폰 ─ 동의 후 켬 ─ POST(text/plain, JSON) ─▶ 연구실 Apps Script 웹앱 ─▶ 연구실 Google 시트 (탭: participant · records · measures · daily)
```

- 참여자 Google 로그인이 **필요 없습니다**(`clientId` 불필요). 앱은 `https://script.google.com/macros/s/…/exec` 모양의 주소만 받습니다 — 다른 주소는 설정이 없는 것으로 봅니다.
- 보내는 것은 엑셀과 같은 숫자 표입니다(참여자는 무작위 번호 `P-xxxxxxxx`). 이름·연락처·「나의 금연/금주 이유」·검사 장소·기기 이름·사진은 들어가지 않습니다. 받는 쪽도 자기 번호의 줄만 받습니다.
- 켠 직후·기록이 바뀐 뒤 8초·앱을 열 때 따라잡기 등 보내는 시점은 Drive 저장과 같습니다. 보낼 때마다 **그 연구 번호의 줄을 통째로 바꿉니다**(중복 없음).
- 보내기 직전에 ① 작업 세대 ② 그 순간 저장소에 적힌 동의를 다시 확인합니다(`labPost`). 끄면 진행 중 요청을 중단합니다.
- 「보낸 자료 지우기」: 먼저 참여를 끄고, 그 연구 번호의 줄을 지워 달라는 요청(`delete`)을 보냅니다. 실패하면 참여는 꺼진 채로 남고 화면에 알립니다.

## 연구실이 할 일 (순서)

1. 연구실 Google 계정에서 시트 하나를 만들고 id 를 복사합니다(주소의 `/d/` 와 `/edit` 사이).
2. 새 Apps Script 프로젝트에 `docs/apps-script/research-sink.gs` 를 붙여 넣고, 프로젝트 설정 → 스크립트 속성 `SHEET_ID` 에 그 id 를 넣습니다.
3. 배포 → 새 배포 → 웹 앱 → 실행 계정 「나」 · 액세스 「모든 사용자」. 처음 한 번 권한(시트 열기)을 승인합니다.
4. 나온 주소(…/exec)를 `research-config.js` 의 `labUrl` 에 넣습니다(공개되는 값 — 열쇠가 아닙니다). 동의 문구·버전·IRB 와 함께 `enabled:true` 는 **교수님 확인 뒤에**.
5. 시트는 코드가 만듭니다(첫 전송 때 탭과 머리글). 열 이름이 앱과 다르면(`header_changed_…`) 받지 않으니 틀 파일을 쓰거나 비워 두세요.

## 한계 · 알아 둘 것

- **이 주소를 아는 사람은 누구나 보낼 수 있습니다**(앱이 공개 코드라 숨길 수 없음). 받는 쪽이 연구 번호 형식 · 크기 · 열 수를 검사하고 자기 번호의 줄만 받으며 `_log` 탭에 남기지만, 가짜 번호로 채우는 것은 막지 못합니다. 이상하면 새로 배포해 주소를 바꾸세요.
- 코드로 시험한 것은 앱 쪽(가짜 fetch)뿐입니다. **Apps Script 실행·시트 기록은 확인하지 못했습니다**(이 환경에서 배포할 수 없음). 배포한 뒤 시험 번호로 한 번 보내 보고 시트에서 확인하세요.
- Google 은 브라우저에서 이 주소로 보내는 요청을 연구 참여자의 IP 와 함께 받습니다(연구실 Google 계정의 Apps Script 로그).
- 기기에서 보낸 뒤에는 앱이 회수할 수 없습니다 — 지우기는 요청이고, 연구실이 시트에서 확인해야 확정됩니다.
- 한 번 보낸 자료를 분석에 쓰는 규칙·보관 기간은 IRB 문서가 정합니다.
