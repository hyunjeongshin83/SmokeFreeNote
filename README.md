# 금연노트 · SmokeFree Note

금연 일수·아낀 돈·건강 회복을 보여주고, 흡연 욕구를 기록하도록 돕는 금연 도우미 웹앱(PWA)입니다.
[MediNote](https://github.com/hyunjeongshin83/MediNote)와 같은 디자인·고령친화 원칙으로 만들었습니다.

## 화면
- **시작 설정** — 금연 시작일, 담배 종류(일반·궐련형·액상), 하루 흡연량, 가격, 나의 금연 이유
- **오늘** — 금연 일수(초 단위), 안 피운 개비, 아낀 돈, 되찾은 시간, 다음 건강 회복 단계,
  「지금 담배가 당겨요」 5분 버티기 타이머
- **기록** — 흡연 욕구의 세기·기분·상황·옆에 흡연자·넘긴 방법·흡연 여부. 저장하면 그 자리에서 대처법 한 가지
- **통계** — 지난 7일 당김·피움, 시간대별·상황별·기분별 순위, 측정값, 시도 기록
- **건강** — 금연 20분 ~ 15년 회복 타임라인 (WHO·CDC 일반 안내 기준)
- **도움** — 금연상담전화 1544-9030, 서울시 금연 지원, 보건소 금연클리닉, 알림 설정, 기기 연결 안내, 큰 글씨, 내보내기·가져오기

## 실행
`index.html`을 브라우저로 열면 됩니다. GitHub Pages에 올리면 휴대폰 홈 화면에 앱처럼 설치할 수 있습니다.
안드로이드 앱(APK)은 Actions 탭 → 「안드로이드 APK」 → Artifacts 에서 받습니다 (디버그 빌드 · 셸은 `android/`, 계획은 `docs/NATIVE.md`).

## 데이터
모든 기록은 이 기기(localStorage)에만 저장됩니다. 서버로 보내지 않습니다.

> 금연노트는 금연을 돕는 기록장이며, 진료를 대신하지 않습니다.
